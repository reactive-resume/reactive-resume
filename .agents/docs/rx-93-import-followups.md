## Repaired ownership and bounded work

V9's claim that Education-first layouts always retained complete fields/description was false. Independent v9 review found single-year, month-year and empty first periods followed by a range merged two records; the projection then deleted fields that base retained. V10 identifies corroborated school/degree and area/location rows per record before assigning dates. Single dates and ranges use the existing shared date semantics. The tested single-line right-header continuation is folded by stream/font/lane/right-edge evidence; multiple right-only continuation lines remain limited as listed below. Every unassigned span remains description text; uncertain geometry keeps the generic parse instead of rewriting a merged chunk.

Strict source assertions now cover all 54 original reviewer Education failure PDFs and 180 permanent real exports across all 18 templates: single/month-year/empty first periods, reverse order, two singles, three mixed/reverse records, wrapped headers at loose typography, and linked recovered headers. Whole Education items, normalized dates, complete descriptions and source-word retention are compared. These cases establish the tested geometry contract, not a universal Education roundtrip. The original 180 full-section variants remain unchanged and passing.

Known same-stream section ownership and the existing labelled-row check close the earlier Education-as-heading regression. The extra row-trailing-cell guard was not load-bearing and was removed in V10; it receives no fix credit. Known same-stream sections bound identity collection. Page continuation retains body columns even when a text glyph begins above page origin; body-style continuation rows remain owned by the preceding section. Larger name typography cannot become an inset contact field. Website keeps the first HTTP annotation; additional linked identity labels survive as custom fields. When no website exists in source and only custom links are rendered, an untagged PDF can give identical geometry: the first custom link becomes website and the remaining links stay custom. All link text/targets survive, but original slot semantics are ambiguous. No GitHub/LinkedIn keyword guess is used.

The shared geometry owner indexes page/y neighborhoods, caches heading/annotation evidence and charges candidate visits. Dense input is rejected by a deterministic preprocessing-pair cap before pairwise geometry, or falls back when candidate budget is exhausted. The existing flat parser then runs and complete harvested line text is also retained in Summary. This intentionally duplicates content already assigned to sections; it does not produce a clean schema roundtrip. This is bounded degradation, not exact field recovery for arbitrary tables. Time thresholds supplement structural budget tests; abort timers do not bound synchronous work.

## Existing mapping and layout limits

- A degree wrapping into two right-only continuation lines can merge two Education records in nine templates (including Azurill, Gengar and Pikachu), assigning the second range to the first record and moving the second record into description. All source words survive; V9 and V10 behave identically on the reviewer examples. The tested single-line continuation does not establish multi-line degree fidelity. See the independent review’s 18-template long-degree oracle.
- Role-first Education and `inline`, `date-column`, `compact`, `eyebrow`, or two-column Education layouts can swap or merge fields while retaining text. These valid exported layouts are outside the strict stacked/default-order geometry contract; no universal layout claim is made.
- Grade-only right cells and degrees containing `•` have ambiguous untagged boundaries: grade can become degree, or a degree suffix can become grade. Text remains, but original field identity is not inferred from vocabulary.
- Skills, languages and interests retain text but flatten proficiency/keywords into separate entries. Numeric rating values represented only as graphics cannot be inferred from text alone.
- Profiles can split network/username; linked annotation labels and targets are not fully reconstructed there.
- Awarder, certification issuer, publication publisher, volunteer location and reference position/phone can remain in description rather than their dedicated fields. Some page-seam reference and Award URL cases still fail source equality; base/v8 also fail those exact fields. Raw differences are retained rather than waived as successful imports.
- A trailing undated Inline role, blank-company records and progression `roles[]` still have pre-existing association limits (independent v8 P3). They are not counted as fidelity passes.
- A newly probed Education-only page with one one-line sidebar skill can still lack enough independent column evidence; Leafish/with SQL alone imports no Education in both v9 and V10. This pre-existing sparse-column limit is retained in `/tmp/rx93-rework-v10/new-leafish.json`, not certified by the positive wrapped-header fixtures, which use the reviewer's normal proficiency row.
- The extreme Glalie narrow rail still maps wrapped Skills/Summary tails to custom labels `s`/`y`. Frozen v8 produces identical custom fields/text; V9 preserves every fragment but does not certify this mapping (`narrow-baseline.json`).
- Localized semantic headings, nested/ordered list structure, ambiguous wrapped name boundaries and exact styling remain incomplete. Exported uppercase/letter-spaced labels and glyph substitution are distinct from import loss; independent text evidence is retained.
- Identical untagged geometry can represent different company/title order when place evidence is absent. Accepted ambiguity remains; no English company/title vocabulary is used to invent semantics.

Original senior/freelancer PDFs remain exact and freshly tested through protected API, SQL and owner GET: 10/30 and 4/12 records/bullets. Local bullet leading, hanging indentation, cross-page prose separation, mixed-font spaces/split-word controls, custom-only blank identity, long headers and singleton/empty periods remain mandatory regression coverage. No universal schema/style roundtrip claim follows from adapter parity or a passing-case count.
