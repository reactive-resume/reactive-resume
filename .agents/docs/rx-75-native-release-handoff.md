# RX-75 native release gate

Employer-form filling adds `react-native-webview` 14.0.1. Both platforms require a new native binary; an OTA update cannot add this module. Deploy the additive packet API before releasing dependent clients.

Do not mark native acceptance complete from Chromium, host WebKit, Hermes export, or compilation alone. Verify the reviewed packet, per-page approval and revocation, exact attachments or visible manual fallback, navigation, disposal, and absence of submission on iOS and Android.

The installed iOS development binary initially failed with `RNCWebViewModule` missing when loading the RX-75 bundle. Rebuild with the linked module before device testing. Store signing, upload, deployment, and installed-fingerprint comparison remain separate release gates.
