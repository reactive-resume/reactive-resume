The command bar is a search box that runs commands. Use it to open a resume or application by name, jump to any page,
switch the theme or language, or prepare a question for the assistant, without reaching for the mouse.

## Open the command bar

Press <kbd>⌘</kbd> <kbd>K</kbd> on a Mac or <kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and Linux. It works on every page,
including inside the editor. On **Documents**, **Applications** and **Settings**, you can also select **Search or
run…** at the top of the sidebar.

To close it, press <kbd>Esc</kbd> or press <kbd>⌘</kbd> <kbd>K</kbd> again.

## Run a command

<Steps>
  <Step title="Type what you're looking for">
    Start typing to filter the list. For example, type "theme" to find **Change theme to…**, or "trash" to find
    **Trash**.
  </Step>
  <Step title="Pick a row">
    Use <kbd>↑</kbd> and <kbd>↓</kbd> to move, then press <kbd>Enter</kbd>, or select the row with the mouse.
  </Step>
  <Step title="Start over if you need to">
    Some rows open a second list, such as your resumes or the list of languages. To get back to the first list, press
    <kbd>Esc</kbd> to close the command bar, then open it again.
  </Step>
</Steps>

## What you can do

The command bar groups its rows by what they do. Rows that need an account appear or become available once you're
signed in.

### Search for…

| Row                         | What it does                                                                                                                                                                                     |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Resumes**                 | Lists your resumes, most recently edited first. Type to filter by name, then press <kbd>Enter</kbd> to open one in the editor. The first row, **Create a new resume**, opens the **New** dialog. |
| **Applications**            | Lists your job applications. Type a company or role to filter, then open one to see its details. **Save job** starts a new one.                                                                  |
| **Assistant conversations** | Lists your past conversations with the assistant. Opening one takes you to its document with the conversation showing.                                                                           |

### Preferences

| Row                     | What it does                                                      |
| ----------------------- | ----------------------------------------------------------------- |
| **Change theme to…**    | Choose **Light theme**, **Dark theme** or **Match system theme**. |
| **Change language to…** | Choose one of the 55 languages the app is available in.           |

### Go to…

| Row              | Where it goes                                                                              |
| ---------------- | ------------------------------------------------------------------------------------------ |
| **Home**         | The Reactive Resume home page.                                                             |
| **Documents**    | Your resumes and cover letters.                                                            |
| **New document** | Opens the **New** dialog.                                                                  |
| **Trash**        | Documents you moved to Trash.                                                              |
| **ATS checker**  | The public [ATS checker](/guides/using-the-ats-checker) for any PDF resume.                |
| **Applications** | Your job application tracker.                                                              |
| **Save job**     | Opens the Save job dialog.                                                                 |
| **Settings**     | Opens a second list with **Account**, **Profile**, **Preferences** and **AI & developer**. |

## Ask the assistant

When you're signed in, anything you type also appears as a last row: **Ask the assistant "…"**, with your text in the
quotes. Choosing it prepares an unsent draft for the [assistant](/guides/using-the-assistant).

<Frame caption="Type a request, then choose the Ask row">
  <img
    src="/images/guides/using-the-command-bar/command-bar-ask.webp"
    alt='The command bar with "Make my summary shorter" typed in the search box and a single row under Ask: Ask the assistant "Make my summary shorter".'
  />
</Frame>

- **In the editor**, the question is about the document you have open. The assistant panel opens with your question in the composer. Review it and press Send.
- **Anywhere else**, choose a resume or letter from the document picker. Reactive Resume opens that document and fills the composer. Nothing is sent until you press Send and approve the destination. If you have no documents, create one first.

The assistant needs an AI provider. If you haven't connected one, the assistant panel helps you set one up first. See
[Connecting an AI provider](/guides/using-ai).
