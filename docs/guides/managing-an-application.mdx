Use the details sheet to manage one application, and its workspace to work on fit, answers, interviews and replies. Select an application in the List, Board or Calendar view to open it. The sheet slides in from the right (on a phone, it fills the screen).

At the top you see the role, the company and location, and **View posting** when a posting was saved. **View posting** shows the saved posting text and what the job asks for, or opens the job link if only a link was saved.

## Open the application workspace

Select **Open workspace** at the bottom of the details sheet. Each application has its own **Fit**, **Apply**, **Interview prep**, **Practice**, **Debrief**, **Messages** and **Library** tabs. **Ask the coach** opens a conversation beside the current tab.

Saved applications open on **Apply**, where the preparation card names the current step through the posting, base resume, reviewed tailoring, optional cover letter, form answers and readiness review. Select the documents for this job in its rows, open their editors with **Edit**, and download their PDFs from each row's options menu. Preparing, editing and downloading never marks the job applied. After submission is recorded, **What you sent** lists the sent versions, each row's options menu edits or downloads the current draft, and **View recorded answers** opens the saved answers.

Start with [Career and Application Workspaces](/guides/career-overview), or [prepare your first application](/guides/first-career-application). Your shared facts and stories live in **Career → Knowledge**; answers, interview preparation and messages stay with the job.

## Moving to another stage

The row of bars under the title is the stage stepper: **Saved**, **Applied**, **Screening**, **Interview** and **Offer**, or your own stages in your order (see [Customizing application stages](/guides/customizing-application-stages)). With many stages, the stepper scrolls sideways. Below it you see the current stage and how long the application has been there.

- To move one stage forward, select **Move to _next stage_** (for example **Move to Offer**).
- To jump to any stage, forwards or back, select its name in the stepper.

For a **Saved** job, select **Mark as applied** after submitting. If you applied to the same company before and never heard back, the dialog lists those applications. It's only advice; you can still confirm. Confirm the **Application date**, choose the resume and cover letter you actually sent (or **None**), and check only the attached PDFs you submitted. Unchecking an attached PDF removes it from the application. Confirming saves the selected documents' current versions and moves the job to **Applied**.

**Open application** opens the original job link in another tab. Opening it or preparing documents keeps the job at its current stage.

Each move is added to the activity history. **Mark as applied** uses the date you confirm; other moves use today's date. You can change a stage date later (see [Keeping notes and history](#keeping-notes-and-history)).

## Planning the next step

**Next step** shows what this application needs now. Reactive Resume works it out in this order:

1. The next interview that hasn't finished yet.
2. Otherwise, the follow-up you set.
3. Otherwise, for **Applied**, how long ago you applied, turning into "No reply in _n_ days" after 10 days; for later stages, how long you've been waiting to hear back.

A **Saved** application shows "Not applied yet", and a closed one shows its reason. Overdue follow-ups and long waits are highlighted in amber.

## Seeing what you sent

For a **Saved** job, **Documents for this job** shows the resume and cover letter you're preparing. After submission, this section becomes **What you sent**.

- Before the application reaches **Applied**, a linked document reads "Linked · not sent yet".
- When you confirm submission, Reactive Resume saves the current version of each selected document. The row then reads "Version sent _date_", plus the resume's Check score at that moment. Choose the actual submitted documents even if you prepared a different copy.
- **Open** opens that sent version, read-only, in the document's history. Select **Back to now** there to return to the latest version.

If nothing is linked yet, **Prepare a resume** and **Write a letter** create one for this job. You can copy, import or create a resume and edit it manually without AI. See [Tailoring a resume for a job](/guides/tailoring-a-resume-for-a-job). To link a resume you already have, open **⋯** > **Edit details…** and pick it under **Resume**.

Sent snapshots stay accessible while a linked document is in Trash. In the workspace, **Apply → Mark as applied** records the current written answers, document versions and stage together.

Recording submission here also updates **Apply**: **Review checks** keeps its three content checks, with no outstanding instruction to submit or mark Applied. Your earlier manual review checks remain unchanged, including after later stage moves.

### Attaching a PDF instead

If you sent a file made elsewhere, select **Attach a file instead**, then **Attach a resume file (PDF)** or **Attach a cover letter file (PDF)**. Only PDF files are accepted. Select the file name to open it, or **×** to remove it.

## Editing the key facts

Below **What you sent** are four facts:

- **Salary** and **Source**: select the value to edit it in place. Press <kbd>Enter</kbd> or select elsewhere to save, or <kbd>Esc</kbd> to cancel.
- **Applied**: the date you applied (a dash for **Saved** applications).
- **Contact**: the first contact's name, with "and _n_ more" when there are others.

### Contacts

Select the **Contact** value to see every contact. Select **Add contact**, then enter a **Name** and, if you like, a role, a label (such as Recruiter, Hiring manager, Referral or Interviewer), an email and a phone number. Emails and phone numbers become links you can select. Select **×** next to a contact to remove it.

### Tags

Type in **Add a tag** and press <kbd>Enter</kbd> to add a tag. Select **×** on a tag to remove it. Tags are searchable from the Applications page.

## Keeping notes and history

**Notes** is a free-form space for anything to remember about the job. It saves automatically a moment after you stop typing, and also when you close the sheet.

**Activity** is the dated history of the application: stage changes, notes and interviews, newest first.

- To add a dated note, type in **Add a note…** and select **Add**.
- To change an entry, hover over it, open its **⋯** menu and select **Edit…** (for a note, you can change the text and the date; for a stage change, the date). For an interview, the menu has **Edit interview…** instead, or select the interview itself.
- To remove an entry, select **Delete…** in the same menu and confirm. The entry that marks when the application entered its current stage can't be deleted.

Dates matter: Insights uses stage dates to work out how quickly people reply. If you add an application after the fact, adjust the dates so they match what happened.

## Editing all details

Open **⋯** at the top of the sheet and select **Edit details…** to edit everything in one form: **Company**, **Role / title**, **Location**, **Salary range**, **Source**, **Stage**, **Job posting link**, the linked **Resume** or an uploaded resume PDF, a **Cover letter** PDF, **Tags**, **Follow-up date**, **Follow-up note** and **Notes**. Select **Save changes** when you're done.

If you've [connected an AI provider](/guides/using-ai), the form also has a **Job description** section at the top. Select it to expand it, then paste the full posting there and Reactive Resume fills in the company, role, location and salary; select **Fill fields** to run it again.

## Closing an application

When an application ends, close it rather than deleting it, so its history still counts in Insights.

<Steps>
  <Step title="Select Mark as closed…">It's at the bottom of the details sheet.</Step>
  <Step title="Choose a reason">
    Pick **Not selected**, **I withdrew**, **Accepted another offer** or **No response**. If you've added your own
    Closed stages, choose one under **Stage**; a stage with a preset outcome, such as **Ghosted**, doesn't ask for a
    reason.
  </Step>
  <Step title="Confirm">Select **Mark as closed**. Linked documents aren't changed.</Step>
</Steps>

<Frame caption="Choosing why the application closed">
  <img
    src="/images/guides/managing-an-application/close-this-application-dialog.webp"

You can also close applications from a board card's **⋯** menu, or several at once from the List view. To bring a closed application back, turn on **Show closed**, open it and select **Reopen**. It returns to **Applied** (your standard Applied stage, whatever you've named it).

## Deleting an application

Open **⋯** at the top of the sheet, select **Delete…** and confirm. The application, its history and any PDF files you attached to it are deleted permanently; there is no Trash for applications. Your resumes and letters are not deleted.
