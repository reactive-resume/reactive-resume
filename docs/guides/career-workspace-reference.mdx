Use this page to look up a control or limit. For a guided start, see [Prepare your first application](/guides/first-career-application).

Preferences, pasted Messages, Apply questions/answers and application Notes keep unsaved drafts on this browser/device. Pending saves flush when leaving or backgrounding. Recovered drafts require review before replay, so stale text does not overwrite newer server state automatically. Sign-out clears local account data. Small requests may finish after navigation; durable recovery also covers larger drafts and interrupted requests.

Offers display application outcomes, mark **Latest** versions and compare two versions of one application as changes. **Compare offers** starts with the current application's newest terms. **Remind me** and the application follow-up share one date/note; deletion clears both after Undo expires. Attached PDFs count in **Sent** and have a **10 MB** client and server limit.

## Where things live

| Place                                                   | Purpose                                                                       |
| ------------------------------------------------------- | ----------------------------------------------------------------------------- |
| **Career → Today**                                      | Notifications, discovered roles, your next three interviews and schedules.    |
| **Career → Coach**                                      | Conversations across your search.                                             |
| **Career → Knowledge → Facts**                          | Statements about your experience, sources, corrections and coaching controls. |
| **Career → Knowledge → Stories**                        | Situation, Task, Action, Result and Reflection with supporting facts.         |
| **Career → Knowledge → Preferences**                    | Target roles, places, search countries, salary and work preferences.          |
| **Career → Offers**                                     | Two saved offer versions and unanswered questions.                            |
| **Applications → application details → Open workspace** | Work on one job.                                                              |
| **Settings → AI & developer**                           | AI connections, default provider and web access.                              |
| **Settings → Preferences**                              | Account timezone and display preferences.                                     |

## Application workspace tabs

| Tab                | Main action                                 | What stays with the job                                                         |
| ------------------ | ------------------------------------------- | ------------------------------------------------------------------------------- |
| **Fit**            | **Check fit**                               | Requirements, their origin, supporting evidence and preference checks.          |
| **Apply**          | **Draft**, **Tighten**, **Mark as applied** | Editable form answers, backing facts, checklist and submitted answer snapshots. |
| **Interview prep** | **Plan my preparation**                     | Timed plan, short briefing, stories and questions for an interview.             |
| **Practice**       | **Hear it**, **Get feedback**               | Typed or spoken attempts and feedback.                                          |
| **Debrief**        | **Review my answer**                        | A recalled real interview answer, observations and practice priorities.         |
| **Messages**       | **Add offer**, **Read it for me**           | Employer message, suggested reply and reviewable application changes.           |
| **Library**        | **Open in…**                                | Earlier generated material and saved offer or answer versions.                  |

Saved jobs open on **Apply**, where the preparation card names the current step as its heading with that step's action, and shows the **Posting**, **Resume** and **Cover letter** rows with **Edit** and an options menu (download PDF, copy, write a letter, clear). The step follows missing posting text, documents, answers and your manual review checks. AI is optional. Submitted jobs show **What you sent** with per-document draft options and **View recorded answers**; **Review checks** counts only the checks you tick. The other initial tabs follow the application's stage and interview timing. Select any tab to work elsewhere. The context column shows the next step, people, documents and notes for the job.

The native iPhone app opens the relevant tab through a task-named action in application details, such as **Prepare application** or **Draft a follow-up**. Workspace arrows reveal additional tabs when the strip is wider than the screen. Native Knowledge uses inline **Facts**, **Stories** and **Preferences** choices. [Native iPhone controls](/guides/editing-on-mobile#native-android-and-iphone-apps) also explains unsynced recovery and form dismissal.

## Library versions

**Employer-form packet** in **Apply** reviews contact details, visible selected-resume work history, letter text and chosen scoped answers for one exact URL. Explicit approval saves named document versions and their exact PDFs without AI, submission or a stage change. Download the private packet for the desktop helper. On iPhone and Android, **Open employer form in browser** supports manual completion with copyable answers and approved PDF downloads; mobile autofill is not offered. Missing/stale sources fail visibly. See [Review a packet](/guides/writing-application-answers#review-a-packet-for-one-employer-form).

The conservative desktop Greenhouse, Lever and Ashby adapters are verified only against fictional standard-control shapes in host browsers. Current ATS upload behavior remains unverified. Existing values, sensitive questions, framework/custom controls, additional pages, account steps and captcha need explicit answers or manual completion.

Generated fit checks, briefings, practice feedback, debriefs and message reviews are saved. Drafted or tightened form answers first need **Accept**; answers are copied into Library when recorded through **Apply → Mark as applied**.

**Add offer** is available in **Career → Offers** and the current application's **Messages** tab on web and mobile. It saves structured terms linked to an application without an AI connection or provider request. Currency and pay period are explicit; the currency starts as the last saved offer's, and the less common terms sit under **More options**. Blank amounts remain unknown, and zero is a known amount. Without any application, the action reads **Add an application first**. Optional response deadlines use the account timezone. Saving an offer for an application before **Offer** moves it to **Offer** with **Undo**. Undo keeps the terms and restores the prior stage. Applications already at **Offer** or closed keep their stage. The newest terms stay in view above **Add a newer offer**. **Next step** leads with a reply deadline, a follow-up if set, or an offer decision. Saving sends no reply. Offer-stage applications without terms appear separately, each with **Add offer**. Loading or failed application metadata does not count as an empty list; use **Try again** on web or **Retry** in the native app after a failure. Saved offers remain available during this lookup.

**Library** lists items newest first and offers filters by type. Removing the last item in a selected type returns the list to All. **Open in…** opens an earlier version read-only in its tab; **Back to current** returns to current work. Offer items open in Career → Offers.

Changes to Knowledge, the posting or documents can make an old result out of date. An old version records what was produced then; it is not automatically rewritten.

Sent resume and letter versions are document snapshots shown under **What you sent**. They are separate from the latest editable document and remain accessible while that document is in Trash. See [Managing an application](/guides/managing-an-application#seeing-what-you-sent).

## Coach context and AI actions

**Ask the coach** opens application coaching beside a workspace tab. The coach receives the job and tab context selected for that conversation. You can start another conversation or reopen one from its history.

A new conversation suggests three starters drawn from what your account holds: preparing for your next interview when one is coming up, weighing an offer when an application is in the Offer stage, and reviewing found roles when discovery has some, before general ones such as turning an accomplishment into a story. A starter only fills in the question; nothing is sent until you choose it.

In Career → Coach, context controls include:

| Control          | What it includes when on                                                                                                                                                                                                                      |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Applications** | Summaries of your applications.                                                                                                                                                                                                               |
| **Knowledge**    | Active facts, eligible stories and career preferences. With Knowledge off, the coach also remembers nothing.                                                                                                                                  |
| **Web research** | Access to public research through the selected web service; off by default. Search terms go to that service. Without a search service it reads **Web research · Set up** and opens Settings; the coach can still read public links you paste. |

Before each coach web search, review the exact query and select **Search the web** or **Skip**. A proposed story also needs **Save story** approval before it becomes part of Knowledge. These choices work on web and mobile.

Choices persist for that conversation. Earlier messages in the same chat can already contain information shared before a control was turned off.

The privacy line also says what the coach may keep: whether it asks before remembering facts you state, remembers them automatically, or never does. **Change** opens the memory setting. To keep a message yourself in any mode, choose **Remember** under it, review the wording, type and (in a job's workspace) whether it is for that application only, then **Remember**. This saves your own words and sends nothing to an AI connection. A fact remembered automatically in a job's workspace says it is for that application only; **Use for all applications** shares it, and **Undo** forgets it.

When you correct, switch off or forget a fact, the coach stops sending messages written before that change, because they may repeat what you withdrew. The conversation marks where that happened, and the privacy line says those messages aren't sent. Start a new conversation to keep context together.

A reply you stop, or one cut short, stays marked after you reopen the conversation. **Continue** asks the coach to carry on from what it said; **Try again** asks again when it had said nothing. An empty reply shows no **Used** chips.

If the AI connection a conversation used is switched off or removed, the conversation says so and sends nothing until you choose the connection it uses next. This applies to the career coach, a job's coach and the editor assistant. A job's coach has the same **Knowledge** and **Web research** controls and connection menu as Career → Coach. **Change connection** appears only when the provider caused a failure, such as a rejected key or a rate limit; a lost internet connection says so instead.

Workspace buttons such as **Check fit** and **Read it for me** are separate AI actions. Their privacy lines describe their own inputs; chat context choices do not turn those inputs off. They use the default usable AI connection. Scheduled preparation requires a selected connection and never falls back to the default. If you delete or switch off its connection, or change its key, model or address, review the paused schedule, choose a tested connection and approve it before enabling work again. [Provider selection](/guides/using-ai#which-provider-is-used) explains this further.

## Discovery review

Preferences offers **Suggest target roles (optional AI)** with explicit connection, resume and enabled shared Knowledge controls. Generated roles remain editable drafts until **Use reviewed roles in preferences** and a successful save. Manual preferences work without AI. Existing schedules keep their saved query. See [Find roles while you are busy](/guides/finding-roles-automatically).

Today separates **Preference phrase matches**, **Keyword overlap** and optional AI **Fit** after tracking. Text overlap does not verify salary, workplace or eligibility. Cards name the source, last search sighting, and recorded query/check time when available; older results show unknown provenance. Publication dates are unknown and checks can become stale. Select roles for **Track selected** or **Dismiss selected**; independent failures remain available to retry. Individual dismiss keeps Undo; bulk dismiss is immediate. Tracking only creates a Saved application.

## Schedules

| Kind               | Settings                                                                 | Result                                   |
| ------------------ | ------------------------------------------------------------------------ | ---------------------------------------- |
| **Find roles**     | Search, first run, local time; every day, every 3 days or every week.    | New checked postings wait in Today.      |
| **Interview prep** | Interview, AI connection; 24 hours before, 2 hours before or Morning of. | Saved briefing and a Today notification. |
| **Remind me**      | Application, date and local time.                                        | A one-time reminder in Today.            |

Interview times and calendar day grouping in Applications, its workspace and Today use your account timezone. When that isn't the timezone of the device you're using, times show their zone, for example "16:56 UTC", and Today offers **Use this device's timezone** to switch in one step. Stage changes and notes keep their recorded whole-day dates.

New schedules use the account timezone from **Settings → Preferences**; existing schedules retain their saved timezone when edited. Morning of means 08:00 on the interview day, or two hours before interviews starting before 10:00. Saving a preparation schedule whose run time has passed makes it due now, and the form says so. A new preparation schedule starts at **2 hours before** when the interview is less than 24 hours away.

Each schedule in Today shows how its latest run went. A one-time schedule reads **Running** while its run is queued or being retried, **Done** once it finished, and **Failed · open to try again** in red when its last try failed; a repeating schedule whose last run failed reads **Last run failed**. Open the schedule to check its application and AI connection, then save it to run again.

Find roles and other web searches target the countries in **Where you're looking for work** under **Career → Knowledge → Preferences**: up to three, your account timezone's country until you change it, or none to search anywhere. Untouched UTC accounts adopt the device timezone's country on their first search or enabled discovery schedule. Each country is a separate search with the web service.

An account can keep up to 100 schedules; delete ones you no longer need to add more. The schedule switch pauses work while keeping settings. Editing the interview moves its briefing schedule. Removing an interview pauses related preparation schedules and produces a notice. Recurring searches keep their local time across daylight-saving changes; missed runs are coalesced rather than all replayed.

Interview and schedule forms reject local times skipped by a daylight-saving change. Choose a valid time in the selected timezone instead of accepting an automatic one-hour shift.

Delivery depends on server scheduling and connections. The browser can be closed. **Also email…**, when offered, requires a verified account email and email delivery configured by the administrator. Email copies are optional; in-app notices remain in Today.

Self-hosters: see [Career scheduling operations](/contributing/career-platform#operate-scheduled-work). Node/Docker uses a server timer; Vercel and Cloudflare use their native schedulers. Installation limits can delay due work.

## Voice

Text feedback uses your selected text AI connection. Reading questions and transcribing answers are separate tasks chosen in **Voice settings**.

| Item              | Limit or behavior                                                                                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Recording         | Up to two minutes per answer.                                                                                                                                                                    |
| Audio upload      | Nonempty WebM, MP4/M4A, MP3, WAV or Ogg, at most 2 MiB; the interface says 2 MB.                                                                                                                 |
| Read aloud        | A supported speech connection, otherwise the browser's voice where available. Sends the question text.                                                                                           |
| Transcription     | A supported transcription connection, otherwise browser dictation where available.                                                                                                               |
| Browser dictation | Available in supported Chrome, Edge and Safari environments; not Firefox. Permission and platform support still matter.                                                                          |
| Fallback          | **Type** remains available when recording or dictation does not work.                                                                                                                            |
| Transcript        | Check and edit before requesting feedback. Provider transcripts keep original and edited text distinguishable.                                                                                   |
| Raw recording     | Not stored by the Reactive Resume server. Provider processing follows that provider's policies.                                                                                                  |
| Local audio       | Cleared after successful provider transcription unless you choose to keep it locally for download. A failed transcription keeps it for retry; local audio clears when the answer panel unmounts. |

Speech connections may charge separately from text AI. Browser speech does not use your AI-provider account; the browser maker may process audio for dictation. The page names who handles each action. See [Practice one answer](/guides/preparing-for-interview-day#practice-one-answer).

## Your data

| Action                         | Effect                                                                                                                                                                                                                   |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **Correct** a fact             | Keeps earlier text in history and flags linked stories for review.                                                                                                                                                       |
| Switch **Use in coaching** off | Keeps the fact but excludes it from new coaching context.                                                                                                                                                                |
| **Forget** a fact              | Removes its content and evidence links after the Undo window. Leaves the source resume, message or file alone.                                                                                                           |
| **Use for all applications**   | Promotes an application-private fact to shared Knowledge.                                                                                                                                                                |
| Delete a Library item          | Removes that saved result after the Undo window; does not erase sent employer messages.                                                                                                                                  |
| Export account data            | Includes career preferences, facts and revisions, stories, saved items, workspace data, schedules, notifications, discovery, jobs, stored voice transcripts and career conversations. Provider credentials are excluded. |
| Delete account                 | Removes your dependent career records along with account data. See [Deleting your account](/guides/deleting-your-account).                                                                                               |

Undo notices for Career deletions and applied message changes last six seconds. Once committed, deletion is not an ongoing trash or restore feature. Exported copies, previously sent material, provider-retained data and installation backups have their own lifetimes.

Knowledge can support Fit, answers, preparation, practice and message reviews as well as Coach. Each AI action names the selected connection and the context it sends. Facts with coaching switched off, forgotten facts, unsupported stories and stories awaiting correction review are excluded from new context.

Unsent Coach messages, story drafts, practice answers and edited recruiter replies survive navigation and refresh within the same browser tab and signed-in account. Successful sends or saves clear the corresponding draft. Browser storage must be available for refresh recovery.

## When something does not work

A failed load shows an error and **Retry**. It does not mean your records are empty or your saved privacy choices have changed. Library results remain read-only; return **Back to current** before changing a plan or remembering a fact.

| What you see                    | What to check                                                                                                         |
| ------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| No AI action is available       | If connections failed to load, use Retry. Otherwise connect and test a provider in Settings; choose a usable default. |
| An AI request fails             | Read the error; check the connection, model access and provider quota. Library work remains available.                |
| Interview prep asks for a round | Add the relevant round under Next step → Edit.                                                                        |
| A saved result is read-only     | Choose Back to current before editing.                                                                                |
| No discovery results            | Check whether the schedule is on, its run time and web connection. A search can finish without new usable roles.      |
| A briefing or reminder is late  | Check timezone and schedule state. On a self-hosted installation, ask the administrator to check scheduler delivery.  |
| Email copies do not arrive      | Verify your address and check installation email configuration. Look in Today for the in-app notice.                  |
| Microphone is blocked           | Allow it for this site in browser settings, choose an audio file where available, or type.                            |
| Transcription failed            | Retry the current recording or type; check the chosen speech connection.                                              |
| A claim is wrong                | Edit the draft and correct its source fact. Review linked stories and rerun affected AI work when needed.             |

## Profile

**Settings → Profile** stores application-only details separately from Career preferences and documents. Web and native mobile support manual create/edit, **Save** or **Update**, **Manage profile** for reloading saved data, exporting and confirmed deletion, without AI. The last-updated time appears beside the save action. Existing locations, office days, notice period and minimum base salary remain in **Career preferences**; requested salary and relocation have separate meanings. Missing authorization, sponsorship and relocation answers remain **Unknown**. No self-identification is collected.

Private profile content stays out of automatic AI context, MCP results and document/public-link exports. Explicitly entered application answers keep their own values and submitted snapshots. Account export includes the profile; account deletion cascades it. Conflicting guest/permanent profiles stop account linking until the user exports and deletes one. [Detailed controls](/guides/building-career-knowledge#keep-application-details-private).

## Set up AI without leaving a task

**Set up AI** opens the shared connection setup in place, retaining typed input. Every AI request names its provider, model and data for approval. With no AI, **Messages → Save message without AI** saves the pasted message in the workspace. Discovery states its search requirement before you fill the schedule; **Set up web access** retains the schedule form. Editing a scheduled preparation connection's key, model or address pauses affected schedules until you enable them again.

### Documents and application details

Use **Stage, details and timeline** in the workspace to open the application record, change its stage,
edit details, or log a dated update. **Notes** holds things to remember and share with the coach;
**Log an update** adds a dated timeline entry.

For a saved job, **Use an existing letter** links a letter from Documents. Documents also offers
**Link to application…** for resumes and letters, and **Write a letter…** on a resume. When starting
a new letter, choose **Resume for a new letter**, or **No resume** for a standalone letter.
A letter recorded as sent keeps its application link; pickers label unavailable targets **Letter already sent**.
Builders offer a back link to their application. Submitted versions remain immutable; current drafts stay editable.
