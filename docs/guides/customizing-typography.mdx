The **Typography** category in Design controls body and heading fonts, sizes, weights and line height. **Page** controls density and spacing.

## Pick your fonts

<Steps>
  <Step title="Open Typography">
    In the editor, select **Design** (or press <kbd>2</kbd>), then open **Typography**.
  </Step>
  <Step title="Choose a body font">
    Under **Body**, open **Font** and search by name. The list is alphabetical and each font appears in its own
    typeface. Select one to apply it.
  </Step>
  <Step title="Choose a heading font">Do the same under **Headings**.</Step>
</Steps>

## Set the text size

Set **Size** under **Body** and **Headings** separately. Each accepts 6 to 24 pt in steps of 0.1 pt. Body text around 10–11 pt reads comfortably on screen and paper.

<Tip>
  Dragging a slider counts as one change, so a single <kbd>⌘</kbd> <kbd>Z</kbd> (<kbd>Ctrl</kbd> <kbd>Z</kbd> on Windows
  and Linux) undoes the whole drag.
</Tip>

## Choose a density

In **Design → Page**, **Density** sets the line height of your body text and the vertical spacing in and between entries:

| Density     | Line height | Vertical spacing |
| ----------- | ----------- | ---------------- |
| **Compact** | 1.35        | 4 pt             |
| **Normal**  | 1.5         | 6 pt             |
| **Roomy**   | 1.65        | 8 pt             |

If you set a body line height or spacing that does not match a preset, no density is selected.

<Note>
  Self-hosting operators can [mirror Computer Modern fonts for server PDFs](/self-hosting/fonts). This setting does not
  change browser font previews or Google-hosted fonts.
</Note>

## Use any font

<Steps>
  <Step title="Open the font editor">Open **Design → Typography**.</Step>
  <Step title="Choose a body font">
    Open **Font** under **Body** and type part of a font's name to search. Each font is shown in its own typeface.
    Choose one to apply it.
  </Step>
  <Step title="Choose a heading font">Do the same under **Headings**.</Step>
</Steps>

<Frame caption="Search fonts by name">
  <img
    src="/images/guides/customizing-typography/font-family-search.webp"
    alt="Advanced Typography with the font family search filtered to Merriweather results"
  />
</Frame>

The list contains Google Fonts plus the PDF standard fonts Helvetica, Courier and Times-Roman. Fonts for Chinese, Japanese, Korean, Arabic, Hebrew, Thai, Indic scripts (such as Devanagari, Bengali, Tamil and Telugu), Amharic and Khmer text are included, and missing characters fall back to a matching Noto font so they still print.

Self-hosted instances can serve these fonts from their own [font mirror](/self-hosting/fonts). If that mirror contains only a subset of the catalog, its operator must add a missing family before it can be exported.

If none of the available fonts can draw a character, the PDF shows a question mark and leaves room for it so the following text stays readable. The export warning names the missing character. Your saved text stays unchanged, so you can choose another font or edit the character and export again.

### Exact typography settings

**Design → Typography** has the same fields for **Body** and **Headings**, plus one **Hyphenation** switch for both:

<Frame caption="Set body and heading fonts separately">
  <img
    src="/images/guides/customizing-typography/advanced-typography.webp"
    alt="Typography with Body and Headings font, weight, size, line height and Hyphenation controls"
  />
</Frame>

| Field                                      | What it does                                                                                                                                                           |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Font**                                   | The font, from the full list. Choosing a new family picks regular and bold body weights, preferably 400 and 700 when available, or one heading weight, preferably 600. |
| **Weights** (body) / **Weight** (headings) | Which weights to use, from those the font offers. Body text can use several (for example 400 for regular and 700 for bold).                                            |
| **Size**                                   | Any size from 6 to 24 pt, in steps of 0.1 pt.                                                                                                                          |
| **Line height**                            | A multiple of the font size, from 0.5 to 4.                                                                                                                            |
| **Hyphenation** (one switch for all text)  | Breaks long words between syllables, using the language set in **Page**. Useful for languages with long compound words, such as German.                                |

Sizes are stored separately for body text and headings; changing one does not change the other.

<Note>
  Cover letters keep their own Typography controls in Design mode. See [Writing a cover
  letter](/guides/writing-a-cover-letter).
</Note>
