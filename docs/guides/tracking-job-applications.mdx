**Applications** is where you keep track of the jobs you're going for. Each application holds the role, the company, the saved job posting, the resume and letter you sent, your contacts, notes and a dated history. It also works out what each application needs next, such as an interview coming up or a follow-up that's due.

For focused work on one job, open its details and select **Open workspace**. [Career and Application Workspaces](/guides/career-overview) explains Fit, Apply, interview preparation, practice, replies and saved results. Shared experience and search schedules live under **Career**.

To open it, select **Applications** in the sidebar (on a phone, it's in the bottom tab bar).

## How stages work

Every application sits in one stage. The first five stages form a pipeline you move through in order:

| Stage         | Use it when                                                              |
| ------------- | ------------------------------------------------------------------------ |
| **Saved**     | You found the job but haven't applied yet.                               |
| **Applied**   | You sent your application.                                               |
| **Screening** | A recruiter or hiring manager got back to you, or you have a first call. |
| **Interview** | You're in the interview process.                                         |
| **Offer**     | You received an offer.                                                   |
| **Closed**    | The application ended, whatever the outcome.                             |

You can rename, recolor and reorder stages, and add your own, such as **Take-home assignment** or **Ghosted**. Each one you add counts as one of these stages. See [Customizing application stages](/guides/customizing-application-stages).

You can close an application from any stage. Closing asks for a reason (**Accepted offer**, **Not selected**, **I withdrew**, **Accepted another offer** or **No response**), which Insights uses later. Closing from **Offer** starts on **Accepted offer**. Closed applications are hidden until you turn on **Show closed**. See [Managing an application](/guides/managing-an-application#closing-an-application).

<Note>
  When an application with a linked resume or letter reaches **Applied** or a later stage, Reactive Resume saves a copy
  of each as a "Sent to *company*" version. You can always open exactly what you sent, even after you keep editing the
  document.
</Note>

## Choosing a view

In the web app, use the tabs above the list to switch views. Your choice is kept in the page address, so a bookmark opens the same view. In the native mobile app, open **Applications** and use the view selector below the heading: **List**, **Board**, **Calendar** or **Insights**. All four views are available on phones and tablets.

<Tabs>
  <Tab title="List">
    The default view. Categories that usually need you first appear first: **Interview**, **Offer**, **Screening**, **Applied**, **Saved**, then **Closed** when shown. Custom stages within a category follow your configured stage order.

    - Select a group heading to collapse or expand it.
    - Within each group, rows follow **Next step**: dated interviews and follow-ups first, soonest first, then the application that has waited longest in its stage. The wait counts from the stage's own date, such as the stage date in an imported CSV, not from when the row was added or last changed. Moving between custom lanes in the same stage does not restart that clock. Web and native use the same ordering; equal dates keep a stable order.
    - Select the **Role**, **Next step** or **Updated** column heading to sort within each group. Select it again to reverse the order.
    - The **Next step** column shows the next interview, the follow-up you set, or what the stage is waiting on: how long ago you applied, **Waiting to hear back** after screening, **Waiting for interview feedback** once your interviews are done, **No interview scheduled** in Interview without an interview date, or **Decide on the offer** in Offer. It turns amber when something is overdue, when you've had no reply for 10 days or more, and for an offer to decide.
    - The **Sent** column shows an icon for a linked resume and a linked letter. It says **None** in amber when an application was sent without a linked document.
    - Select a row to open its details.

  </Tab>
  <Tab title="Board">
    One column per stage, with a card for each application. Drag a card to another column to move it to that stage. Each card also has a **⋯** menu with **Move to…**, **Mark as closed…** and **Delete…**, which is handy if you prefer the keyboard. When **Show closed** is on, a **Closed** column appears too. Dragging a card there asks why it ended before closing it, so Insights can use the outcome. In the mobile app, the **Closed** column is always the last column on the board.

In a narrow phone browser, the web page shows **List**, **Insights** and **Calendar**, and list rows show the company and next step on a second line. **Board** remains available on wider browser layouts. The native mobile app offers all four views on phones and tablets.

## Finding applications

Type in **Search applications** to filter the list as you type. Search looks at the role, company, location, contact names and tags. If nothing matches, select **Clear search**.

In the web app, **Show closed** adds closed applications to the List, Board and Calendar views. The native mobile calendar shows only open applications. Insights always counts every application.

## Acting on several applications at once

In the List view on a computer or tablet, select the checkboxes next to the applications you want. A bar appears at the bottom of the page with:

- **Move to…** to move them all to one stage
- **Add tag** to add the same tag to each
- **Close…** to close them all with one reason
- **Delete…** to delete them permanently (you're asked to confirm)
- **Clear** to deselect

Moves and closes show at once with **Undo** in the message. They're saved when the message goes away, or when you leave the page; **Undo** puts the selected applications back where they were, without recording a stage change. If you move one of them again before then, here or on another device, that later move stays, even if it moved away and back to the same stage: the bulk move leaves it and says so, and **Undo** leaves it too. Other edits, such as a note, don't stop the move. If you move the same applications again before the first move is saved, or while a move of one of them from its own menu or details, **Mark as applied**, or a message's changes are still being saved, the later move is saved after the earlier one, so it's the one that stays. Removing a stage in **Stages** moves its applications to another stage of the same kind without counting as a change. Tags and deletions are saved straight away.

Selection follows the visible rows. Hiding closed applications, collapsing a stage or changing the search removes hidden selections before a bulk action.

## Follow-up reminders

A reminder appears above the list when applications owe a follow-up: the follow-up date you set is due, or an application has been at **Applied** for 10 days or more without a reply.

- With one, the reminder names it, for example "Harborlight Labs: no reply for 17 days." Select **Open** to go to that application.
- With several, it counts them, for example "8 applications need a follow-up." Select **Show** to list only those applications, then **Show all** to return to the full list.

Select **×** to dismiss the reminder. Dismissing is remembered on this device, so those applications don't come back in it here. The same rules feed **Needs you** in [Career → Today](/guides/career-overview), which also lists interviews in the next week and offers to decide. The native mobile app shows the same reminder above its list.

## Opening Applications from anywhere

Press <kbd>⌘</kbd> <kbd>K</kbd> (<kbd>Ctrl</kbd> <kbd>K</kbd> on Windows and Linux) and type a company or role to find an application from the first list, or choose **Applications** to go to the page. Run **Save job** to open the add dialog. See [Using the command bar](/guides/using-the-command-bar).
