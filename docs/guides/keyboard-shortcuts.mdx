This page lists the keyboard shortcuts in Reactive Resume, grouped by where they work.

On a Mac, use <kbd>⌘</kbd> (Command). On Windows and Linux, use <kbd>Ctrl</kbd> wherever this page shows <kbd>⌘</kbd>.
The shortcut help shows the keys for your platform.

## See shortcuts for the current page

Press <kbd>?</kbd> outside a text field to open **Keyboard shortcuts**. You can also select **Keyboard shortcuts**
in the lower-right corner of the web app, the command bar, or an editor's document menu. In the native app,
use the keyboard button in a header or the **Keyboard shortcuts** action in search. Help reads the commands
registered on the current page, so the editor and Applications show their own actions. List commands require
focus inside their list. Closing help returns focus to the control that opened it.

Turn off **Single-character shortcuts** in help or **Settings → Preferences** if you use speech input or prefer to use the visible controls.
This also turns off <kbd>?</kbd>; the keyboard button still opens help. The preference stays on this browser or
device. On web it covers <kbd>N</kbd>, <kbd>/</kbd> and editor mode numbers as well. Native list commands require
the list's explicit keyboard mode. Shortcuts with Command or Ctrl keep working.

The help surface shows the current page's named commands and the control for turning character shortcuts off.

<Note>
  Shortcuts made of a single key, such as <kbd>N</kbd> or <kbd>1</kbd>, don't work while you're typing in a text field,
  so they never get in the way of your writing. Shortcuts with <kbd>⌘</kbd> can work while typing. Help does not open
  during text composition or over another dialog, menu or sheet. Opening help pauses background app shortcuts. In the
  native app, sheets and alerts pause background app shortcuts.
</Note>

## Everywhere

| Shortcut                                    | What it does                                                          |
| ------------------------------------------- | --------------------------------------------------------------------- |
| <kbd>?</kbd>                                | Open shortcut help outside text fields; on web, press again to close. |
| <kbd>⌘</kbd> <kbd>K</kbd>                   | Open or close the [command bar](/guides/using-the-command-bar).       |
| <kbd>Esc</kbd>                              | Close the command bar.                                                |
| <kbd>Backspace</kbd>                        | In an empty command-bar search box, go back one list.                 |
| <kbd>↑</kbd> <kbd>↓</kbd>, <kbd>Enter</kbd> | In the command bar, move between rows and run the selected one.       |

## Documents, Applications, Career and Settings

| Shortcut         | What it does                                                                     |
| ---------------- | -------------------------------------------------------------------------------- |
| <kbd>N</kbd>     | Open **New** for the section you're in.                                          |
| <kbd>/</kbd>     | Jump to the search box on **Documents** or **Applications** in the web app.      |
| <kbd>Enter</kbd> | In the **Documents** search box, open the first result.                          |
| <kbd>↓</kbd>     | In the **Documents** search box, move to the first result.                       |
| <kbd>Esc</kbd>   | In the **Documents** search box, clear the search; press again to leave the box. |
| <kbd>Enter</kbd> | Save a document name while renaming it on its card.                              |
| <kbd>Esc</kbd>   | Cancel renaming a document on its card.                                          |
| <kbd>Esc</kbd>   | Clear the Documents selection when focus is outside a text field.                |

In the native mobile app, use <kbd>⌘</kbd> <kbd>F</kbd> on an iPad hardware keyboard or <kbd>Ctrl</kbd> <kbd>F</kbd>
on Android to open or refocus the current collection's search. Your filter stays in place. These native search
shortcuts pause while a sheet or alert is open.

## Resume editor

| Shortcut                                              | What it does                                                                                                      |
| ----------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| <kbd>1</kbd>                                          | Switch to **Write**.                                                                                              |
| <kbd>2</kbd>                                          | Switch to **Design**.                                                                                             |
| <kbd>3</kbd>                                          | Switch to **Check**.                                                                                              |
| <kbd>4</kbd>                                          | Switch to **Share**.                                                                                              |
| <kbd>⌘</kbd> <kbd>Z</kbd>                             | Undo your last change.                                                                                            |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd>                | Redo.                                                                                                             |
| <kbd>Ctrl</kbd> <kbd>Y</kbd>                          | Redo (Windows and Linux).                                                                                         |
| <kbd>⌘</kbd> <kbd>P</kbd>                             | Download the PDF. This replaces the browser's print dialog; to print, use **Print** in the document menu.         |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>E</kbd>                | Open **Download & history** on the **Download** tab.                                                              |
| <kbd>⌘</kbd> <kbd>J</kbd>                             | Open or close the assistant.                                                                                      |
| <kbd>⌘</kbd> <kbd>0</kbd>                             | Fit the page to the window.                                                                                       |
| <kbd>⌘</kbd> <kbd>S</kbd>                             | Nothing to do: a message reminds you that changes are saved automatically.                                        |
| <kbd>Esc</kbd>                                        | Clear the block selected on the page. In **Design**, also stop previewing a template.                             |
| <kbd>⌥</kbd> <kbd>↑</kbd> / <kbd>⌥</kbd> <kbd>↓</kbd> | With a section or entry title focused in **Write**, move it up or down (use <kbd>Alt</kbd> on Windows and Linux). |

While your cursor is in a text field, <kbd>⌘</kbd> <kbd>Z</kbd> and <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>Z</kbd> undo and redo
your typing in that field instead of the last change to the resume.

The download and share shortcuts do nothing while you're offline, because they need a connection.

## Formatting text

These work in rich text boxes, such as a summary or an entry's description. See
[Formatting text](/guides/formatting-text) for the toolbar.

| Shortcut                               | What it does                               |
| -------------------------------------- | ------------------------------------------ |
| <kbd>⌘</kbd> <kbd>B</kbd>              | Bold.                                      |
| <kbd>⌘</kbd> <kbd>I</kbd>              | Italic.                                    |
| <kbd>⌘</kbd> <kbd>U</kbd>              | Underline.                                 |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>8</kbd> | Bulleted list.                             |
| <kbd>⇧</kbd> <kbd>⌘</kbd> <kbd>7</kbd> | Numbered list.                             |
| `- ` or `* ` at the start of a line    | Start a bulleted list.                     |
| `1. ` at the start of a line           | Start a numbered list.                     |
| `**text**`                             | Make the text bold.                        |
| `*text*`                               | Make the text italic.                      |
| <kbd>Esc</kbd>                         | Close the **Improve selected line** panel. |

In fields that collect keywords, press <kbd>Enter</kbd> or <kbd>,</kbd> to add the keyword you typed.

## Assistant

| Shortcut                      | What it does                            |
| ----------------------------- | --------------------------------------- |
| <kbd>Enter</kbd>              | Send your message.                      |
| <kbd>⇧</kbd> <kbd>Enter</kbd> | Start a new line in your message.       |
| <kbd>Esc</kbd>                | Stop the assistant while it's replying. |

## Proposed edits

When the assistant or Check proposes edits, select an edit in the list to focus it, then:

| Shortcut                    | What it does                       |
| --------------------------- | ---------------------------------- |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Move to the previous or next edit. |
| <kbd>A</kbd>                | Accept the focused edit.           |
| <kbd>R</kbd>                | Reject the focused edit.           |
